# Proposal

## Why

Сервис `wallet-docs` отвечает по индексу OpenSpec-спек, но индекс кто-то должен наполнять и
обновлять: спеки живут в 11 репозиториях и меняются при каждом архиве change'а. Заливку
берёт на себя Jenkins по уже принятой схеме контура: скрипт в `wallet-infra/infra/env/`,
запуск через общую обвязку `env_run.sh`. Сервис необязательный, поэтому заливка должна
молча пропускаться, если его нет.

## What Changes

- Новый скрипт `infra/env/docs-index.sh <prod|test> <репозиторий|all>`: собирает
  `openspec/**/*.md` репозитория (из рабочей папки организации на хосте), формирует JSON и
  отправляет `PUT /docs/index/{repo}` в контейнер `wallet-docs` внутри сети контура.
- Токен заливки не покидает контейнер `wallet-docs`: запрос выполняется `docker exec` в самом
  контейнере, где `INDEX_TOKEN` уже есть в окружении. В аргументах, логах и выводе токена нет.
- Мягкий отказ: если профиль `docs` выключен, контейнер `wallet-docs` не запущен или вернул
  ошибку, скрипт пишет предупреждение и завершается кодом 0 (для `all` — после обработки
  остальных репозиториев). Строгий режим `--strict` возвращает ненулевой код.
- Новый Jenkins-job `docs-index` в BuildPlatform (вне git): параметры `ENV` и `REPO`
  (`all` по умолчанию), запуск вручную и ночью; мягкий отказ помечает сборку `UNSTABLE`.
- Токен заливки `INDEX_TOKEN` живёт в `wallet-docs.env` контура; контроль прав — как у остальных секретов.

## Capabilities

### New Capabilities
- `docs-index-upload`: заливка индекса документации в `wallet-docs` из рабочих папок репозиториев скриптом контура и Jenkins-job'ом; мягкий отказ без сервиса.

### Modified Capabilities

## Impact

- **wallet-infra**: `infra/env/docs-index.sh`, README (`infra/env`), проверка прав `wallet-docs.env` в `lib.sh` (необязательный файл).
- **BuildPlatform** (вне git, перед правкой — резервная копия): `jobs/docs-index/Jenkinsfile`, регистрация job'а.
- **wallet-docs**: контракт `PUT /docs/index/{repo}` (change `docs-service`).
- **Репозитории организации**: читаются только `openspec/**/*.md`; исходный код и секреты в индекс не попадают.
