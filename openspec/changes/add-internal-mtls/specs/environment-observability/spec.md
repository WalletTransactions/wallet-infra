# Spec Delta

## ADDED Requirements

### Requirement: Метрики контура собираются и при внутреннем mTLS
Стек метрик SHALL продолжать собирать `/metrics` всех сервисов контура, когда в контуре включён mTLS между сервисами. Prometheus MUST предъявлять клиентский сертификат, выпущенный CA именно того контура, чьи цели он опрашивает, и проверять сертификат сервиса по CA этого контура. Сертификат одного контура MUST NOT позволять опрашивать цели другого.

#### Scenario: Один контур в mTLS, другой нет
- **WHEN** на test режим внутреннего mTLS включён, а на prod выключен
- **THEN** в Prometheus цели обоих контуров в состоянии up, а метрики test собираются по TLS, prod — по HTTP

#### Scenario: Сертификат чужого контура
- **WHEN** Prometheus пытается опросить цель prod сертификатом, выпущенным CA test
- **THEN** цель в состоянии down, а метрики другого контура не подмешиваются

#### Scenario: Откат режима
- **WHEN** на test выключают mTLS
- **THEN** цели test возвращаются в состояние up по HTTP без правки дашбордов Grafana
